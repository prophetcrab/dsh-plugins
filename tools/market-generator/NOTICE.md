# Vendored generator

`src/` is a pinned copy of `apps/plugin-market-generator` from
[deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness), used so the refresh
workflow can regenerate the index without cloning the whole DSH workspace.
